# NAA — GitHub Standalone 7.7.0

Versão estática/PWA do Núcleo de Avaliação da Aprendizagem para GitHub Pages.

Esta edição não usa PHP, SQL nem servidor externo. Autenticação, usuários, mensagens e configurações operacionais ficam no navegador; datasets e uploads pedagógicos ficam no IndexedDB.

## Primeiro acesso

No primeiro login de um navegador novo, o CPF/e-mail e a senha informados criam o Administrador Local (CEO Programador) daquele dispositivo. Depois, novos usuários podem ser cadastrados no próprio NAA.

## Publicação

GitHub Pages deve usar **GitHub Actions**. O endereço esperado do projeto é:

`https://laudineisantana9-png.github.io/naa-lssystem/`

> Limite do GitHub Pages: não existe banco central entre navegadores/aparelhos. Esta versão é autônoma por dispositivo.
