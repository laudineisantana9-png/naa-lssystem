NAA 7.7.0 · GITHUB STANDALONE

- Sem PHP, SQL ou naa.lssystem.com.br.
- Login e usuários: localStorage + PBKDF2/SHA-256.
- Datasets/uploads: IndexedDB.
- Mensagens, avisos e LS Meet: funcionamento local no mesmo navegador/origem.
